# 추가 항목 (README에서 옮김)

## 릴리스 노트

### 0.6.6

- 대시보드 키를 Ctrl+글자로 바꿨습니다: `Ctrl+S` 전체 시작, `Ctrl+X` 전체 중지, `Ctrl+R` 전체 재시작(중지 후 시작), `Ctrl+O` 브라우저, `Ctrl+E` 설정. 글자 키 `a`, `x`, `r`, `o`, `e`, `q`는 제거했습니다.
- Ctrl+C로만 대시보드를 닫습니다. `q`와 Esc는 더 이상 닫지 않습니다.
- 단일 서비스 재시작 키를 제거했습니다. 전체 재시작은 `Ctrl+R`입니다.
- 하단 버튼 줄: 전체 시작, 전체 중지, 브라우저, + 추가. 설정, 언어, 닫기 버튼을 제거했습니다. 언어는 `HERDR_DEVRUN_LANG` 또는 `config.json`으로 정합니다.
- `Ctrl+H`로 도움말 팝업을 열고, 하단 줄에 `Ctrl+H 도움말`을 표시합니다.
- `Ctrl+L`로 대시보드 언어를 순환합니다 (시스템 → 각 언어 → 시스템). 고른 언어는 `config.json`에 저장되며, 언어 목록 폼은 제거했습니다.

### 0.5.5

- 대시보드 버튼: 서비스 줄마다 시작/중지, 수정, 삭제, 닫기(`⊗`) 버튼이 있고, 하단 줄에는 전체 시작, 전체 중지, 브라우저, 설정, 추가, 닫기가 있다. 재시작은 `r` 키다.
- 배치: 서비스는 공유 `devrun` space 안의 프로젝트 탭에서 실행하고, 탭의 첫 pane은 대시보드(`control-box`)다.
- 중지(전체 중지 포함)는 프로세스만 끄고 pane을 '중지' 표시로 남기며, 시작은 그 pane을 다시 쓴다. `devrun down`은 여전히 탭을 닫는다.
- 삭제와 닫기는 확인 창을 띄운다. `y`를 누르면 확인된다.
- 중지와 시작 중 나오는 Windows 배치 파일의 "(Y/N)" 질문에는 `Y`로 답한다.
- 전체 시작의 완료 메시지는 이미 실행 중이라 건너뛴 서비스를 실패한 서비스와 따로 보인다.
- Windows에서 설정 파일은 메모장으로 연다.
